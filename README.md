Hydration Reminder App 💧

A mobile application built for Mobile Application Development - Practical Tutorial 06 (Department of Statistics & Computer Science, University of Kelaniya). This project demonstrates how to implement Local Notifications and Multi-Tab Navigation using React Native and Expo.

Features

3-Tab Navigation (expo-router):

Reminder: Set custom hydration reminder messages and configure repeating time intervals (in minutes) to schedule or cancel local device alerts.

Tips: Static educational screen highlighting the key health benefits of staying hydrated.

About: Information about the application and developer details.

Local Notifications (expo-notifications):

Requests OS-level notification permissions on app launch.

Displays foreground alerts even while the app is actively open.

Schedules and cancels repeating local notifications without requiring an internet connection or external server.

Technologies Used

React Native

Expo & Expo Router

Expo Notifications (expo-notifications)

TypeScript

How to Run Locally

Clone the repository:

git clone https://github.com/damsilunidinethya2003-ui/HydrationReminder.git
cd HydrationReminder


Install dependencies:

npm install


Start the Expo development server:

npx expo start -c


Scan the QR code using the Expo Go app on a physical Android or iOS device.
